# Peta Bisnis Proses UNEKA

Aplikasi web (React) untuk peta bisnis proses dan penyusunan Statuta Universitas Eka Harap.
Data tidak disimpan di repositori ini: seluruh data dibaca dari Google Spreadsheet melalui
Google Apps Script (alamat /exec pada `public/konfigurasi.js`).

Setiap perubahan pada cabang `main` dibangun dan diterbitkan otomatis ke GitHub Pages
oleh `.github/workflows/deploy.yml`.
